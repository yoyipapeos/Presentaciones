INTRO

Una primera mirada a las transformaciones lineales

Una transformación toma vectores de entrada y los convierte en otros vectores. Para saber si es lineal, comprobaremos dos reglas: que respete la suma de vectores y la multiplicación por escalares.

01 / IDEA

¿Qué significa que una función sea lineal?

Una transformación T: V → W es lineal si conserva las combinaciones de vectores: sumar y multiplicar por escalares antes o después de aplicar T produce lo mismo.

Aditividad

T(u + v) = T(u) + T(v)

La imagen de una suma es la suma de las imágenes.

Homogeneidad

T(cu) = cT(u)

La imagen de un múltiplo es el mismo múltiplo de la imagen.

Atajo importante: toda transformación lineal debe cumplir T(0) = 0. Si T(0) ≠ 0, ya sabemos que no es lineal. Si T(0) = 0, todavía hay que revisar aditividad y homogeneidad.

Ejercicio B · No es transformación lineal

Regla de correspondencia
T(x, y) = (x + 0.5y + 1, y)

Superposición

T(v₁ + v₂) = T(v₁) + T(v₂)

Comprobación de superposición

Los resultados difieren: el lado izquierdo suma 1 y el derecho suma 2 en la primera coordenada. No se cumple la superposición.

Homogeneidad

T(a v₁) = aT(v₁)

Comprobación de homogeneidad

Por ejemplo, con a = 2, el término constante es 1 en el lado izquierdo y 2 en el derecho. No son iguales y falla la homogeneidad.

03 / MATRICES

Cuando sí es lineal, una matriz la representa

Para transformaciones lineales entre espacios de coordenadas, existe una matriz A tal que T(x) = Ax. Una constante sumada al resultado no puede formar parte de esa multiplicación lineal.

Ejercicio A · lineal

T(x, y) = (x + 0.5y, y)

Su matriz es [ 1  0.5 ; 0  1 ].

Ejercicio B · no lineal

T(x, y) = (x + 0.5y + 1, y)

El término constante desplaza el origen y rompe las propiedades de linealidad.

05 / REPASO

Una lista corta para tus ejercicios

1. Identifica dominio y regla

Escribe qué vectores entran y qué expresión define T.

2. Prueba el vector cero

Si T(0) ≠ 0, concluye inmediatamente que no es lineal.

3. Verifica las dos propiedades

Si T(0) = 0, demuestra aditividad y homogeneidad para vectores generales.

Idea final

Comprueba las propiedades, no te guíes solo por la apariencia.

Una regla es lineal exactamente cuando conserva sumas y múltiplos escalares. Para descartarla, un solo caso que falle es suficiente.

T(u + v) = T(u) + T(v)   y   T(cu) = cT(u)
